# v0.4.0-preview.2：随游戏退出与 UE4SS 双安装包

- 面板绑定真实游戏进程的路径、PID 和创建时间；正常退出或崩溃后自动清理，不因暂停、地图切换或日志停更误退。无游戏时手动打开会提示后退出。
- 同一 Release 分别提供带 UE4SS 的 with-UE4SS 包，以及不含 UE4SS 和根目录代理的 mod-only 包。两者包含相同 Mod、面板和本项目启动组件。
- 整合模式检测已有外部 UE4SS 或代理冲突，避免重复加载；兼容模式复用原运行库，不覆盖公共设置、签名或其他 Mod。
- 外部版本先检测 Lua 接口和 Hook 结果；失败时停用本 Mod。状态页显示实际运行库和验证状态，启动故障日志独立于战斗日志。
- 安装脚本支持外置数据目录、配置和快捷键迁移、启用项更新以及备份回滚。卸载保留共享 UE4SS。

下载适合自己环境的 ZIP，并核对同一 SHA256SUMS.txt。两个 ZIP 内均有对应中文安装步骤。更新前退出游戏，不要同时安装两套运行库。

保留原有分武器帧数和自由快捷键功能；本版不增加停顿强度调节。未知 UE4SS 版本仅尝试能力兼容，不代表所有版本或 Mod 组合已经实测。游戏仍限定 Steam build 26266538 / UE 5.7.4。
