# v0.4.0-preview.3：游戏更新后的启动修复与精简安装包

- 修复 PBZ.exe 更新后因哈希不匹配跳过 UE4SS、导致依赖它的 Mod 无法呼出的问题。加载器和面板启动组件将版本差异记为提示，继续尝试初始化；运行库完整性、重复加载、停用标志和实际错误处理保留。
- 本机 build 26367565 / CL302256 已验证冷启动、runtime_loaded 与同一 UE4SS 下的 F8 木桩菜单。卡肉数值的完整新版回归尚未完成；此前功能验证基线为 build 26266538。
- 两个 ZIP 移除 Install.ps1、Uninstall.ps1、开发架构文档和重复说明，保留对应手动安装 README、运行依赖、许可证与校验清单。
- 卡肉与木桩项目各自独立。本包不含 PBZTrainingDummy，不要求安装木桩。

提供 with-UE4SS 和 mod-only 两个包。已有旧 PBZHitEnhance 根目录加载器的用户必须更新 dwmapi.dll，单独更新 mod-only 不能修复旧代理的版本拦截。保留外置运行库的升级方式见包内 README，避免覆盖现有 mods.txt 和其他 Mod。两个项目的独立整合包不能覆盖叠装。

DLL、面板 EXE 和其运行时是功能必需文件，仍保留。CI 通过后发布；移除安装脚本不代表第三方平台一定不再触发文件审核。
