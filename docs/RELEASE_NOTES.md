首个可分发版本，提供中文卡肉调节面板与随游戏启动自动加载。

- 支持比例、增减帧数与固定帧数，默认 1 倍。
- 首次设置呼出快捷键，后续后台启动并记住设置。
- 移除本机路径，提供独立面板程序，无需用户安装 Python。
- 支持将运行数据放在游戏目录外。
- GitHub Actions 编译 DLL、打包面板，并检查系统接口转发、Lua 回调、配置和包校验。

安装请阅读压缩包或仓库内的中文 README。需要解压完整 zip，把 dwmapi.dll 和 PBZHitEnhance 文件夹放在真实 platform/steam/PBZ.exe 旁；不要使用 Source code 压缩包安装。

支持 Steam build 26266538 / UE 5.7.4。包含玩家受击；未验证所有武器。使用窗口化或无边框游戏模式。CI 不运行游戏。
