按武器类别设置卡肉帧数的预览版，保留 DLL 自动加载和中文快捷键面板。

- 单手、双持、双手重武器分别设置固定帧数、倍率、增减帧数和上限；可独立覆盖或沿用全局。
- 增加仅记录模式，以及最近攻击标签、识别类别、采用设置和帧数变化显示。
- 旧版配置可读取并自动补齐新增字段；新包默认全局 1 倍，各类别继承全局。
- 乱莺剑、白蟒赤练、亡命斩马刀已实测独立 5/7/9 帧，40 次修改均在相邻下游消费中匹配。
- 补充主武器标签映射，当前为 33 条配置中的 25 条建立候选关联；记录含变体和占位，仅三把完成实战验证。剩余标签及特殊招式继续全局回退。
- 验证包含 123 项 Lua 场景、配置迁移、真实面板交互、系统 DLL 转发及独立面板打包检查。

安装时必须使用匹配的 dwmapi.dll、面板与运行数据，不能只更新 DLL。完整安装、外置数据路径和卸载见中文 README。

支持 Steam build 26266538 / UE 5.7.4。按攻击标签分类，可能包含双方匹配命中，不保证只影响玩家攻击；未验证所有武器、招式和材质。帧数为游戏内部单位。CI 不运行游戏。
