# v0.4.0-preview.1：分武器卡肉与自由快捷键

本预览版增加单手刀剑、双持、双手重武器独立卡肉设置，并提供直接按键录入。保留 DLL 自动加载、中文面板与旧配置迁移。

## 新增与修复

- 三个武器类别分别设置固定帧数、倍率、增减帧数和上限；独立覆盖或继承全局。默认全局 1 倍，各类别继承全局。
- 快捷键改为“点击录入按键 → 按下单键或同时按住组合键 → 全部松开 → 保存”，支持 Insert、Ctrl+Insert、A+B 等常规键盘组合；旧 Ctrl+F10 配置可继续使用。
- 修复媒体播放/暂停键持续处于按下状态时，Ctrl+F10 无法呼出的问题。无关普通键或媒体状态不再阻断匹配；额外修饰键仍需与配置一致。支持取消、失焦/超时取消和长按防重复。
- 新增仅记录模式，以及最近攻击标签、识别类别、采用设置和帧数变化显示。
- 扩充三个主武器类别的候选标签；未知类别、能量攻击等沿用全局设置。

## 验证范围

- 离线验证包含 123 项 Lua 场景、配置迁移、真实 Tk 控件测试、按键录入/触发线程测试及媒体键故障回归；打包检查包含系统 DLL 转发、文件哈希和独立面板资源自检。发布任务仅在构建及测试通过后执行。
- 乱莺剑、白蟒赤练、亡命斩马刀完成三类独立固定 5/7/9 帧测试，40 次修改均与相邻下游执行接口参数一致。
- 后续单手 3 倍样本 32 次、4 倍样本 6 次；双持 3/4 倍样本共 9 次，调整后帧数均与相邻下游参数一致；另一次双持原始 0 帧保持不变。
- 当前 33 条主武器配置含变体与占位，其中 25 条有候选标签关联；仅上述三把经过实战验证，不保证全部武器、招式和材质覆盖。

## 安装与升级

下载 `PBZHitEnhance-v0.4.0-preview.1-windows-x64.zip`，不要把 Source code 压缩包当成安装包。`SHA256SUMS.txt` 用于核对下载文件。

先退出游戏与旧调节面板，备份原有 `config.ini`、`ui_settings.json` 及旧安装包，再将匹配的 `dwmapi.dll` 和整个 `PBZHitEnhance` 文件夹安装到真实 `PBZ.exe` 旁的 `platform\steam` 目录。保留或恢复自己的配置；不要只替换 DLL。新版配置无法直接交给 0.3 旧脚本使用，回退时恢复旧配置备份。

如果已设置 `PBZHitEnhance.ini` 的外部 `DataDirectory`，运行数据应更新到该指定目录。完整安装、外置路径、快捷键和卸载步骤见仓库中文 README。

## 当前限制

支持已验证的 Steam build 26266538 / UE 5.7.4。按攻击标签分类，包含双方匹配命中，不保证只影响玩家攻击。面板适用于窗口化或无边框；Windows 保留快捷键可能优先被系统处理，按键不会被面板拦截。

**本版仅调整 Frames，保留原始减速倍率与恢复曲线；没有新增“停顿强度”调节。** 日志确认参数传入执行接口，尚未标定画面的实际停顿时间或长期稳定性。内部帧数不能直接等同于显示帧数或现实毫秒，4 倍帧数也不代表主观打击感强 4 倍。CI 不运行游戏。
